# 知识地图调整方案 v2：突出跨专题联系，按需聚焦

这份文档在 `structure-v2.md` 的基础上，专门调整首页的知识地图。实现时以本文档为准；不清楚或不合理的地方，先问作者，不要自行发挥。

交互效果的示意页（作者已看过并认可大方向）：https://claude.ai/artifact/Asd9wQUJHx7Q9tZPLZP9i2 。示意页里的颜色、节点大小、连线样式和交互方式都可以参考，但代码要按网站现有结构重新实现。

## 1. 设计原则

- **跨专题的联系是地图的主角。** 专题内的联系大多在意料之中，看目录也能猜到；跨专题的联系才是目录替代不了的，任何时候都要清楚可见。
- **同一时间只让一层信息“亮”起来。** 内容变多以后，靠聚焦和淡化来保持清楚，而不是把所有连线同时画在同一个层面上。
- **地图只放有意义的节点。** 不是每个页面都要出现在地图上。

## 2. 哪些页面出现在地图上

- **专题导览（`type: 'overview'`）不出现在地图上。** 导览是专题的入口，不是一个具体概念，放在地图里意义不大。
  - 地图上的**专题名**改为可点击的链接；如果这个专题有已完成的导览页，点专题名进入导览，否则专题名只是普通文字。
  - 导览页的 `next` 连线（例如 导览 → 协方差椭圆）不在地图上画。专题的起点就是导览之后的第一页。
- 在 `pages.js` 里加一个可选字段 `map`，默认 `true`；`overview` 类型默认 `false`。以后如果有别的页面不适合放进地图，也可以手动设为 `false`。
- 计划中的页面**继续显示**（虚线圈），它们相当于路线图。

## 3. 节点样式

| 页面类型 | 样式 |
|---|---|
| 概念页 `concept` | 标准大小（示意页半径约 25） |
| 对比页 `compare` | 略小（约 21），外面多一圈细环 |

- 状态：已完成为实心水彩圆点；计划中为浅色圆点加虚线圈。
- 颜色：用所属专题的颜色。
- 被选中的节点外加一圈深色细环。
- 暂不按连线数量决定大小。等页面多了，再考虑是否突出“枢纽概念”。

## 4. 连线样式

| 连线 | 样式 |
|---|---|
| 专题内的主线（`next`，同一专题） | 细的中性色实线，带箭头 |
| **跨专题联系**（两端属于不同专题，不论 `kind`） | **`--rose` 灰玫瑰色、加粗、虚线**，用一条只轻微弯曲的平滑曲线直接连接两个节点；不能穿过节点、不能压住文字，会压住时稍微加大弯曲来避开，不绕远路。尽量不交叉，但允许交叉；优先保证线条顺滑、不压节点和文字 |
| 专题内的相关（`related`，同一专题） | 细的中性色虚线 |
| 专题内的对比（`compare`，同一专题） | 细的中性色双向箭头 |

## 5. 三种视图

地图上方放三个按钮：

| 视图 | 显示 |
|---|---|
| **默认**（打开时） | 所有节点；专题主线（细）；跨专题联系（突出）。专题内的相关、对比**很淡**（透明度约 0.15），只提示它们存在 |
| **只看跨专题** | 只亮跨专题连线和它们两端的节点，其余淡化 |
| **全部连线** | 所有连线都正常显示 |

## 6. 聚焦交互

| 操作 | 效果 |
|---|---|
| 点一个节点 | 这个节点、和它直接相连的节点及连线都亮起，其余淡化（透明度约 0.15）。右侧卡片显示这一页的信息和所有联系 |
| 再点一次同一节点，或点地图空白处 | 恢复当前视图 |
| 鼠标悬停在连线上 | 浮出一个小提示框，显示这条连线的 `why` |
| 点一条连线 | 只亮这条线和两端节点，右侧卡片显示两页的名字和 `why` |
| 切换视图按钮 | 取消聚焦，切换到对应视图 |

- 连线要有足够宽的透明点击区域（示意页约 16px），方便点中。
- 节点可以用键盘聚焦，按回车或空格选中。
- 淡化和高亮使用短暂的过渡动画，遇到 `prefers-reduced-motion` 时关闭。

## 7. 右侧卡片

| 状态 | 卡片内容 |
|---|---|
| 未选中（默认 / 全部连线视图） | 标题“两个专题之间有 N 处联系”（专题多了以后改为“专题之间有 N 处联系”），下面列出每条跨专题联系的两端和 `why` |
| 选中节点 | 专题名 · 页面类型 · 状态；页面标题和问题；所有联系逐条列出（跨专题的排在最前，用 `--rose` 左边线标出），每条写明“先看 / 接着看 / 相关 / 对比 / 跨专题联系”和 `why`；已完成的页面有“进入”按钮 |
| 选中连线 | 连线类型；“A → B”；`why` |

## 8. 布局

沿用之前的约定，并补充：

- 同一专题内，按 `next` 连线计算层级：横坐标是从专题起点出发的步数，有分叉时上下展开，所有主线箭头从左指向右。
- 多元统计：协方差椭圆 → 特征分解，然后分成上下两条线（上：马氏距离 → T² 检验；下：主成分分析 → PCA vs LDA）。
- 机器学习基础：过拟合在左侧中间，正则化和交叉验证在右侧一上一下；谁在上由程序按“跨专题连线顺滑、弯曲小、不压节点和文字”来选。
- 专题区域用专题颜色的淡淡水彩晕染，范围贴合节点；专题名放在区域左上角，不能被连线压住。
- 节点上下可以稍微错落，连线用柔和的曲线，保留手绘感。
- 可选字段 `pos` 用来手动微调自动布局的位置。
- **窄屏（600px 以下）**：两个专题区域改为上下排列，跨专题连线同样是直接相连的平滑曲线（上端节点的标签可以挪到节点上方，给曲线让路）；文字不能小于 12px，标签不能重叠。

## 9. 以后再做（这次不做）

当页面多到二十多个时，再考虑**两层地图**：

- **专题层**：每个专题是一个大气泡，专题之间的跨专题连线合并成一条，标出联系数量，例如“多元统计 ⇄ 机器学习基础：2 处联系”；
- **页面层**：点开一个专题，展开成它的所有页面。

这次实现时，代码结构上留出扩展的余地即可，不需要提前实现。

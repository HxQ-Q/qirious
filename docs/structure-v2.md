# 网站结构调整方案 v2：专题 + 带理由的知识地图

这份文档是本次结构调整的设计说明。实现时请以它为准；有不清楚或不合理的地方，先问作者，不要自行发挥。

## 1. 为什么要调整

原来的目录只有“主题标签”一个维度，导致：

- 同一页在目录里重复出现（例如“过拟合”既是 1.1 又是 2.1）；
- 分类标准不统一（学科、方法、工作类型混在一起）；
- 编号看起来像顺序，其实没有含义；
- 没有学习路线。

## 2. 新结构

| 层次 | 规则 | 作用 |
|---|---|---|
| **专题**（series） | 每页**只属于一个**专题；专题内有建议阅读顺序 | 目录按专题分组，编号表示阅读顺序 |
| **知识地图** | 页面之间可以任意连线，包括跨专题；**每条连线都要写一句理由** | 发现概念之间的联系 |

- **取消主题标签**（原来的 TOPICS 和 `topics` 字段）。以后页面很多、确实需要按方法筛选时再考虑加回来。
- **页面类型**按需使用，不要求每个专题都具备所有类型。目前用到三种：
  - `overview` 专题导览：这个专题讲什么、页面之间怎么连，先看全貌；
  - `concept` 概念页：一页讲透一个概念，主体是一个直观的画面；
  - `compare` 对比页：把两个容易混淆的方法放在一起看。

## 3. 数据格式（`pages.js`）

```js
window.QIRIOUS = (() => {
  const SERIES = [
    { id: 'mvs', name: '多元统计', color: 'var(--plum)', desc: '…' },
    { id: 'ml',  name: '机器学习基础', color: 'var(--sage)', desc: '…' },
  ];
  const PAGES = [
    {
      id: 'mahalanobis',
      series: 'mvs',
      order: 3,              // 专题内的阅读顺序；导览为 0
      type: 'concept',       // overview / concept / compare
      short: '马氏距离',      // 地图上的短名
      q: '…',                // 页面要回答的问题
      concept: '…',          // 核心概念，顿号分隔
      en: '…',               // 英文名
      status: 'plan',        // done / plan
      url: '',               // 已完成的页面才填
      blurb: '…',            // 一句话介绍
      links: [               // 从这一页出发的连线
        { to: 'hotelling', kind: 'next',    why: '…' },  // 接着看（实线箭头）
        { to: 'xxx',       kind: 'related', why: '…' },  // 相关（虚线）
        { to: 'xxx',       kind: 'compare', why: '…' },  // 对比（双向）
      ],
    },
  ];
  return { SERIES, PAGES };
})();
```

说明：

- 每条连线只需要写在一端；显示时双向都能看到（比如在 B 页也能看到“先看 A”）。
- `why` 是一句完整的话，说明两个页面为什么有关。地图上悬停在连线上、点选节点后的卡片、页面底部的“相关内容”都显示这句话。
- **不再手填 `x`、`y`**：地图按专题自动分区布局（见第 5 节）。

## 4. 页面清单

### 专题一：多元统计（`mvs`）

主线逻辑：**先看懂“一团点的形状”（协方差），再理解形状的主轴从哪来（特征分解），然后用这个形状去量距离（马氏距离），最后把距离用到检验、降维和分类上。** 后面几页都建立在前面的画面上。

| order | id | 类型 | short | q（问题） | concept | en |
|---|---|---|---|---|---|---|
| 0 | `mvs-overview` | overview | 专题导览 | 多元统计在研究什么？为什么说一切从椭圆开始？ | 专题全貌 | Overview: it all starts with an ellipse |
| 1 | `covariance` | concept | 协方差椭圆 | 一团点的“形状”能用什么来描述？ | 协方差矩阵、多元正态分布 | Covariance & the multivariate normal |
| 2 | `eigen` | concept | 特征分解 | 椭圆的长轴和短轴是从哪里来的？ | 线性变换、特征值与特征向量 | Linear maps & eigen-decomposition |
| 3 | `mahalanobis` | concept | 马氏距离 | 为什么看起来更近的点，反而可能更“异常”？ | 马氏距离 | Mahalanobis distance |
| 4 | `hotelling` | compare | T² 检验 | 同时检验两个均值，为什么不能分别做两次 t 检验？ | Hotelling T²、接受域与拒绝域 | Hotelling's T² vs separate t-tests |
| 5 | `pca` | concept | 主成分分析 | 把很多维的数据压到一两维，怎样损失最少？ | 主成分分析、方差解释比例 | Principal component analysis |
| 6 | `pca-lda` | compare | PCA vs LDA | 都是找一个方向投影，为什么 PCA 可能完全分不开两类？ | 主成分分析、线性判别分析 | PCA vs LDA |

blurb：

- `mvs-overview`：用一张图串起这个专题：协方差描述形状，特征分解找出主轴，马氏距离按形状量距离，再分别通向检验、降维和分类。
- `covariance`：拖动相关系数和两个方差，看点云和等高线椭圆怎样拉伸、旋转，协方差矩阵里的数字又怎样跟着变。
- `eigen`：调整一个 2×2 矩阵，看单位圆被变成什么样的椭圆；特征向量正好指向椭圆的主轴。
- `mahalanobis`：拖动两个点，比较普通距离的“圆”和马氏距离的“椭圆”，看哪个点才是真正的异常值。
- `hotelling`：拖动样本均值，对比两次 t 检验的“矩形”接受域和 T² 检验的“椭圆”接受域，找出两者结论不一致的地方。
- `pca`：手动旋转一条穿过点云的直线，看投影的分散程度怎样变化，找到让方差最大的方向。
- `pca-lda`：同一份带类别的数据，分别投影到 PCA 和 LDA 找到的方向上，看哪个方向能把两类分开。

links：

| 从 | 到 | kind | why |
|---|---|---|---|
| `mvs-overview` | `covariance` | next | 整个专题从“一团点的形状”开始。 |
| `covariance` | `eigen` | next | 协方差矩阵的特征向量和特征值，决定了椭圆主轴的方向和长短。 |
| `eigen` | `mahalanobis` | next | 马氏距离相当于先沿主轴把椭圆“压”成圆，再量普通距离。 |
| `mahalanobis` | `hotelling` | next | T² 统计量就是样本均值到假设均值的马氏距离的平方，再乘以样本量 n。 |
| `eigen` | `pca` | next | 主成分就是协方差矩阵的特征向量，特征值就是每个方向上的方差。 |
| `pca` | `pca-lda` | next | PCA 只看数据怎样分散，不看类别；LDA 要找的是最能把类别分开的方向。 |
| `mahalanobis` | `pca-lda` | related | 在两类协方差相同、先验概率也相同的假设下，LDA 等价于把点分给马氏距离更近的那一类。 |

## 5. 页面展示的改动

### 首页知识地图

- 按专题**自动分区布局**：每个专题是一片区域（“岛屿”），节点按 `order` 沿一条路径排开，节点颜色用专题颜色。
- 专题内的 `next` 连线画成细线箭头；**跨专题的连线要突出**（例如更粗或用强调色），因为这是地图最有价值的部分。
- `related` 画虚线，`compare` 画双向箭头。
- 鼠标悬停或点选连线时，显示它的 `why`。
- 窄屏（390px）下标签不能重叠。
- 图例相应更新。

### 首页右侧选中卡片

- 显示专题名和页面类型（导览 / 概念 / 对比），代替原来的主题标签。
- “先看 / 接着看 / 相关 / 对比”每一项后面显示对应的 `why`。

### 首页目录

- 筛选按钮改为：全部 + 各专题。
- 按专题分组，每组标题旁显示进度，例如“1 / 3 已完成”，下面一行显示专题的 `desc`。
- 组内按 `order` 排序，编号就用 `order`（导览为 0）；每项显示一个小的类型标记。
- **同一页不再重复出现。**

### 个人主页（`me.html`）

- “我的探索”卡片上的主题小圆点，改为显示专题名。
- 统计数字里的“个主题”改为“个专题”。
- “接下来想弄懂的”列表按新数据生成。

### 实验页（`explore/overfitting.html`）

- 顶部的主题小字改为专题名，例如“机器学习基础”。
- 底部“接着看”改为从 `pages.js` 自动生成，并显示每条连线的 `why`。

# Qirious

> 用更形象直观的方式，走进一个新领域。

Qirious 是一个个人学习网站，用来探索自己感兴趣的领域和知识。

比起直接从定义和公式读起，我更想先“看见”一个概念：拖动数据点，观察模型怎样随之变化；看一段动画，理解一个过程如何展开；或者用一张图，把公式背后的直觉画出来。这里的每一页都从一个具体的问题出发，借助交互实验、动态演示、数形结合或形象的类比来解释它，力求直观，而不枯燥。

随着探索的主题越来越多，首页的知识地图会把这些页面连接起来，逐渐长成一张知识网：哪些概念是基础，哪些是延伸，不同领域之间又有怎样的联系，都能一目了然。

## 关于这个仓库

- 纯静态网站（HTML / CSS / JavaScript），通过 GitHub Pages 发布
- `pages.js`：所有页面的档案，首页的知识地图和目录由它自动生成
- `experiments/`：各个内容页面
- `CLAUDE.md`：项目约定与设计规范

## 名字的由来

**Qirious** = Qi + curious。中文名**淇思**取“奇思”的谐音，Qi也与淇对应。
